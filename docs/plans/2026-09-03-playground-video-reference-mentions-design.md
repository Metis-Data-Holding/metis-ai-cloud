# Playground 视频参考素材与引用设计

## 目标

让参考生成模式中的图片与视频既能被清楚识别，也能按照 BytePlus ModelArk 的内容顺序在提示词中稳定引用。保持现有上传接口、异步任务接口和后端适配器不变，只调整前端素材顺序、组合输入框展示与提示词交互。

## 素材模型

- `VideoInputContent[]` 是提交给 Provider 的唯一素材顺序来源，不再按图片/视频类型重新排序。
- 图片与视频分别独立编号，数组从左到右依次生成 `图片1`、`视频1`、`图片2` 等展示名称和 `@图片1`、`@视频1` 等引用词。
- 首尾帧模式仍按 `first_frame -> last_frame` 排序，不参与参考素材编号。
- 本地视频上传完成后，把签名 URL 放回它在本次文件选择中的原始位置，确保混合选择不会改变引用语义。

## 展示与交互

- 没有素材时显示原有正方形“参考内容”入口。
- 有素材时默认显示正方形堆叠卡片，最后上传的素材位于最上层；最上层卡片底部显示素材名称，右下角显示圆形添加按钮。
- 鼠标悬浮或键盘聚焦素材区时，素材区向右展开：最左侧是“参考内容”入口，后面按上传顺序显示全部正方形素材卡片。
- 视频卡片使用浏览器原生视频首帧作为预览，并显示视频标记；每张卡片保留可访问的删除操作。
- 窄屏和触屏不依赖 hover，素材托盘可横向滚动，控件保持可聚焦。

## 提示词引用

- 提示词占位文案明确说明可以使用 `@` 引用图片与视频。
- 用户在参考生成模式输入 `@` 或 `@图片`、`@视频` 时，展示当前素材列表；选择后把稳定引用词插入光标位置。
- 提交时保留提示词中的 `@图片N/@视频N` 文本，并按相同编号顺序提交 `metadata.content`，适配 ModelArk 的引用语义。

## 分辨率边界

- Seedance 2.0 标准模型在纯文本和仅参考视频场景显示 480p、720p、1080p、4k。
- 只要包含参考图片，隐藏 1080p 并将已有 1080p 归一化为 720p，这是 Provider 的官方限制。
- Seedance 2.0 Fast 继续只显示 480p、720p。

## 验收标准

1. 混合上传图片、视频、图片后，UI 和请求内容顺序一致，名称为图片1、视频1、图片2。
2. 单素材显示顶层卡片与右下角添加按钮；多素材默认堆叠，悬浮或聚焦后展开为按上传顺序排列的托盘。
3. 输入 `@` 可选择已有素材，并把对应引用词插入提示词。
4. 仅参考视频时标准 Seedance 2.0 可选 1080p；加入参考图片后 1080p 消失。
5. 不修改后端上传、视频任务或 Provider 适配器接口。
