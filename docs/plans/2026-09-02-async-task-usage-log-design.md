# 异步任务使用日志展示设计

## 目标

让通用使用日志正确表达异步视频任务的计费阶段。Token 与任务耗时继续保持现状，本次不修改数据写入和展示口径。

## 方案

前端直接根据现有日志结构派生计费阶段，不新增接口或数据库字段：

- 异步任务首次消费日志显示“预扣费”；
- 带 `pre_consumed_quota` 与 `actual_quota` 的正向差额日志显示“补扣”；
- `LogTypeRefund` 继续显示“退款”；
- 其他同步消费日志继续显示“消耗”。

上述标签同时用于桌面表格、移动端卡片和日志详情。Token 列保持 `-`，准确的任务总耗时继续在任务日志展示。

## 兼容性与错误处理

- 不改变后端日志类型、数据库、费用字段、统计 SQL、退款逻辑和任务耗时口径。
- 旧异步日志只要包含现有结构化字段，也可得到一致的阶段标签。
- Token 完成后回填涉及小数精度、日志存储兼容和结算状态，本次明确延期。

## 验证

- 前端测试覆盖：预扣费、补扣、退款及普通消耗标签。
- 运行前端定向测试、类型检查、Lint、格式检查和构建。
